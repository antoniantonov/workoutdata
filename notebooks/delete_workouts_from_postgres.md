# Delete workouts from PostgreSQL

This notebook deletes a list of `workoutId` values from PostgreSQL by calling
`polar.storage.postgres.delete_workout_by_id` for each ID.

The list of IDs below is populated by running the second-to-last cell of
`audit_polar_blob_coverage.md`. That cell rewrites the block between the
`BEGIN_WORKOUT_IDS_PLACEHOLDER` and `END_WORKOUT_IDS_PLACEHOLDER` markers in
this file.

## Setup

```{code-cell} ipython3
import sys
from pathlib import Path

# Add repo root to path
repo_root = Path.cwd().parent if 'notebooks' in str(Path.cwd()) else Path.cwd()
sys.path.insert(0, str(repo_root))

# Load environment variables from notebooks/.env when present.
try:
    from dotenv import load_dotenv

    notebook_dir = Path.cwd() if 'notebooks' in str(Path.cwd()) else Path.cwd() / 'notebooks'
    env_file = notebook_dir / '.env'
    if env_file.exists():
        load_dotenv(env_file)
        print(f"✅ Loaded environment variables from: {env_file}")
    else:
        print(f"ℹ️ No notebook .env file found at: {env_file}")
except ImportError:
    print("ℹ️ python-dotenv is not installed; using existing environment variables")

import importlib

from polar.storage import postgres as postgres_storage
from polar.utils.config import load_configuration

importlib.reload(postgres_storage)

config = load_configuration()

database_type = config.get('DATABASE_TYPE')
if database_type != 'postgres':
    raise RuntimeError(
        f"DATABASE_TYPE is {database_type!r}; this notebook only deletes from PostgreSQL."
    )

print("✅ Configuration loaded")
```

## Delete each workout

```{code-cell} ipython3
if not workout_ids_to_delete:
    print("ℹ️ No workout IDs to delete. Run the audit notebook first.")
else:
    for workout_id in workout_ids_to_delete:
        postgres_storage.delete_workout_by_id(workout_id, config)

    print(f"✅ Finished deletion attempt for {len(workout_ids_to_delete)} workoutId value(s).")
```
